# Mobile App - Image Tampering Detection

This mobile application brings the image forensics model to your smartphone, making tampering detection accessible anywhere.

## Purpose
- **Quick Testing:** Upload or capture images for instant analysis
- **Mobile Access:** No need for a computer to run forensics
- **Real-time Results:** Get tampering probability in seconds

## Features
-  Capture or upload images
-  Tampering detection with confidence scores
-  SHA-256 hash verification
-  Grad-CAM heatmap visualization
-  Export forensic reports
-  Cloud sync to GitHub
